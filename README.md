# TradPlus TaurusX Adapter Swift Package

Swift Package Manager support for the TradPlus TaurusX adapter (15.15.0).

## Installation

```text
https://github.com/tradplus/TradPlusAdSDK-SPM-TaurusX.git
```

```swift
.package(url: "https://github.com/tradplus/TradPlusAdSDK-SPM-TaurusX.git", exact: "15.15.0")
```

Third-party dependency: TaurusX SDK `1.18.2`.

## Notes

- This package automatically resolves `TradPlusAdSDK` 15.15.0.
- Add `-ObjC` to the app target's `Other Linker Flags` if required.
